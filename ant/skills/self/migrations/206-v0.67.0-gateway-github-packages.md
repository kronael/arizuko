# 206 — v0.67.0: a gateway holds the credential, GitHub is a channel, packages install with defaults

Your model credential can now live outside your container, a GitHub repository
talks to you like any other chat, and a package installs with working defaults
or refuses before it writes anything.

## What is different

- **The container can stop holding the model credential.** When your operator
  sets a model gateway, every spawn talks to that gateway, which holds the real
  credential, meters the spend and logs the traffic. Your container carries a
  virtual key only. The model keys are withheld from BOTH sources — the
  operator's own and your personal env-profile row — so a gateway is a real
  boundary and not a suggestion.
- **GitHub arrives as a channel.** A webhook delivery from a registered
  repository or organisation becomes an inbound message, on the same surface
  Telegram and Discord use. You reply to it the same way you reply to anything.
- **You see reply excerpts and your own memory file.** Both were built and
  neither reached your prompt. Every quoted message you answered, you answered
  blind.
- **`PERSONA.md` reaches the system prompt.** `SYSTEM.md` replaces the base
  prompt; `PERSONA.md` adds to it. A group can carry a voice without
  restating the platform contract.
- **A forged identity header no longer reaches an operator page.** Daemon
  dashboards trusted `X-User-*` from any caller that could reach the port.
  They now need proxyd's signed proof behind it.
- **A reply resolves inside its own chat only.** A reply target used to match
  on the message id alone, across every chat.
- **A package says what it needs from `.env`.** A manifest names a key as
  minted-at-install, derived-every-generate, or operator-must-set. The third
  refuses the install until the value exists, so a package never installs and
  then fails to start.

## What you must do

Nothing. Every change is either a fix you get for free or an operator setting.

1. If your operator turned on a model gateway, expect no model key in your
   shell. That is correct. Ask them, do not work around it.
2. If you quoted a message before today and the answer looked wrong, it was:
   you did not receive the excerpt. Re-read the thread if it still matters.
