## v0.58.0 — link context + stability

**New in your prompt: `<link-context>`.** When a message arrives via a chat
link or webhook whose issuer attached context, you'll see a
`<link-context>…</link-context>` block in the prompt. It carries per-link
instructions for how to handle that link's inbound — the issuer authored it,
not the sender. See `/self` → `chat-link.md`.

Stability (transparent, no action needed): chats no longer error out or
forget the thread after a quiet spell (session-resume guard + transcript
retention pinned forever); the typing indicator stays on through long turns;
per-group host data mounts now work.
