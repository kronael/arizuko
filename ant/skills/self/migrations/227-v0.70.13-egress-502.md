## v0.70.13 — egress proxy names the cause of a refusal

The egress proxy gives a different answer for each cause:

- `403 denied: host not allowed` — the host is not on your allowlist.
  Ask for `network_allow`.
- `403 denied: … blocked address` — the address behind the name is
  blocked. A grant for the name does not change this.
- `502 upstream unreachable: <error>` — the host is allowed, but the
  proxy could not resolve or reach it. This is NOT a missing grant.
  Report the body verbatim.

Rules: `self/egress.md`.
