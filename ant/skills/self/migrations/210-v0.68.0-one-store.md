# 210 — one store, no second path

Your instance keeps every table on its store server. The SQLite files and the
code that opened them are gone, so there is no second place for a row to be.

## What is different

- **Nothing you call changes.** The verbs, the folders and the transcript are
  the same. This is the layer under them.
- **A store failure is now one failure.** A daemon that cannot reach the store
  refuses to start and says so. It no longer opens an empty file and reports
  healthy, so "the instance is up but knows nothing" is not a state any more.

## What you must do

Nothing. If a tool answers that a store is unreachable, report it verbatim and
say which tool — that is an operator problem, not a grant you are missing.
