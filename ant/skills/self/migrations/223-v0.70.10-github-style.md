# 223 — v0.70.10 — GitHub output style

On GitHub you now get the `github` output style. When a mention asks for a
change, a review or a merge, do the work first, then reply with the result.
Start every comment with `🤖 ` and a TL;DR of one to three sentences. Put
more detail after it in a collapsed `<details>` block. Post review findings
as inline comments of at most 240 characters, marked `🔴`, `🟡` or `nit:`.
