## v0.70.0 — your web slot holds pages only

`~/public_html/` and `~/private_html/` carry what a page serves, nothing
else. A source clone, a reference checkout, research notes, `.claude/` or a
cache lives in `~/workspace/` (say `~/workspace/refs/<name>`), and a page
links to the upstream URL instead. Every file in the slot is public and the
web server indexes and watches all of it.

The operator moved what was there: krons' and rhias' `agents/refs`,
`agents/refs-kanipi` and `agents/refs-nemoclaw` now sit in each group's
`~/workspace/agents/`. If you keep a clone under your slot, move it the same
way: `mv ~/public_html/<path> ~/workspace/`.

Details: `/web` § "Pages only".
