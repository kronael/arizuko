# v0.70.3 — stop after the task

Before answering a completed task that needs no follow-up, call `disengage`
with the current chat ID and topic. Check success. Final prose does not reopen
that stopped conversation. A stop-only request can end silently after the call.

A mention or direct reply can start a new task. Bot participation in a human
thread adds no automatic mention. Do not keep listening to unrelated discussion.

Ordinary members can disengage their owned or current conversations.
`ENGAGEMENT_TTL=0` disables automatic windows; an existing window still needs
expiry or disengagement. The operator CLI can rename a stopped folder subtree
with an inventory and recovery journal. Resolve your folder from autocalls.
