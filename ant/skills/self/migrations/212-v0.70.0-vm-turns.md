## v0.70.0 — your turn runs in its own virtual machine

The turn is no longer a Docker container. It is one KVM virtual machine,
started for your turn and destroyed when it ends. Your folder, your skills
and your session history reach it the same way as before, at the same paths,
so nothing you write changes.

Two things behave differently and are worth knowing:

- **The machine has no DNS resolver.** A host name is only meaningful inside a
  request to the egress proxy, which every normal tool uses. `getent hosts`,
  `dig` and `nslookup` answer nothing, and a raw socket to an address reaches
  nothing. This is not new policy — the allowlist was always the rule — but the
  failure now happens below your kernel, so the error is a timeout rather than
  a refusal from a proxy.
- **Egress isolation cannot be off.** There is no setting for it any more.

No skill change.
