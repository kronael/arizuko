## v0.60.0 — live status checklists

**New: post a live status checklist and edit it in place.** `send` / `reply` /
`send_file` now return the created message id (`{"ok":true,"id":"…"}`) — capture
it and pass it to `edit` to update that same message. The `progress` skill uses
this: for a genuinely multi-step turn, post ONE checklist and `edit` it to tick
tasks off (☑ done · ⏳ running · ☐ pending), instead of a stream of ⏳ status
pings. Only for real multi-step work — never force a checklist onto a simple
reply. Where `edit` isn't supported (email, WhatsApp, Reddit), fall back to the
usual `<status>` pings.

Delivery fixes (transparent, no action needed): X (Twitter) replies now thread;
permanent Slack send errors (gone channel, dead thread) stop retrying.
