## v0.62.0 — native docker compose packaging

**Infrastructure change, no agent action.** Channel adapters are now native
docker compose fragments (`template/services/<name>.yml`) that docker `include`s
verbatim, instead of the old TOML mini-format. Optional daemons are gated by
`COMPOSE_PROFILES` (derived from the feature flags into a `# --- compose-managed`
block in the data dir's `.env`), not a bespoke `PROFILE` var.

**Operators:** `arizuko generate` auto-converts any legacy `services/*.toml` to
`.yml` on the next run (re-points stale `ROUTER_URL`, extracts routes to
`<name>-routes.json`, deletes the TOML) — a redeploy is enough. Manage the
adapter catalog with `arizuko packages <instance> list | add <name> | remove <name>`.
