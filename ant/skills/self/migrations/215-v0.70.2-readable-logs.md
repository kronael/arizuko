# 215 — v0.70.2: the logs say what happened

Nothing in your folder changes. This release is about what an operator can read.

- A turn that fails terminally now names its cause on the last line it writes, so the
  reason reaches the journal instead of only the turn log on disk.
- The guest's file server stopped reporting its own uid clamp thousands of times an
  hour, so a real error in the same journal is findable again.
- `make lint` and `make test` can both report a real result; neither could before.

If a turn of yours failed with no explanation in the last weeks, the explanation
existed — in `groups/<folder>/logs/container-*.log`. Now it is in both places.
