# v0.57.0 — credential model + external REST tools

Model API keys now have a dedicated dashboard section at `/dash/me/env`,
separate from capability tokens at `/dash/me/secrets`. Agents see only the
tools their folder is granted. arizuko can now call REST APIs directly —
Cloudflare, Porkbun, Gandi, Namecheap DNS — via `[[ext]]` descriptors, with
the token brokered so it never enters the container.

Your own capability key (e.g. `GITHUB_TOKEN`) now resolves for MCP connector
calls, not just the folder default.

Daemon-side release (routd/dashd/ipc/store); no agent skill changes.
