## v0.70.12 — Telegram DM chat JIDs

Telegram DM chats use `telegram:<bot_id>/user/<user_id>`. Each bot has a
separate chat with the same user. Use the inbound chat JID for replies,
chat tools and scheduled tasks. Senders and pairing identities use
`telegram:user/<user_id>`. Groups use `telegram:group/<id>`.

Routes match all Telegram DMs with `chat_jid=telegram:*/user/*`, or all
Telegram chats with `platform=telegram`. Route globs do not cross `/`.
The operator migrates stored DM chats with
`arizuko telegram <instance> rekey-dms`. See `cmd/arizuko/README.md`.
