## v0.59.0 — opt-in release announcements + Slack thread fix

**Announcements are now opt-in.** `/migrate` step (e) posts the release line
ONLY to routes tagged `#announce` (e.g. `chat_jid=slack:… target=folder#announce`),
deduped per server — no more blasting every channel a group touches. A group
with no `#announce` route announces nowhere. Operators tag one channel per
server (Slack/Discord `#random`, a Telegram group); mute by dropping the
fragment. `#announce` is inbound-neutral — the route still triggers normally.

Slack threaded replies that hit a since-gone thread now post at channel root
instead of vanishing (transparent, no action needed).
