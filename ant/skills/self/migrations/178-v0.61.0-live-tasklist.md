## v0.61.0 — live tasklist status (automatic)

**Progress now reports itself.** Plan a multi-step turn with a task list
(the `TodoWrite` tool) and the harness renders it into ONE `⏳` checklist
that edits in place as tasks tick over (`☑` done · `⏳` running · `☐`
pending) — you no longer post-and-`edit` a checklist by hand (the old
`progress` skill dance is gone). Writing the task list IS the update.

`<status>` blocks still cover planless turns; on platforms without editing
(email, WhatsApp, Reddit) it falls back to separate `⏳` notices
automatically. Only real multi-step work earns a task list — never force
one onto a one-line reply. Spec 5/24.
