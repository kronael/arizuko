## v0.61.0 — live tasklist status (automatic)

**Progress now reports itself.** Plan a multi-step turn with a task list
(the `TodoWrite` tool) and the harness renders it into ONE `⏳` checklist
that edits in place as tasks tick over (`☑` done · `⏳` running · `☐`
pending) — you no longer post-and-`edit` a checklist by hand (the old
`progress` skill dance is gone). Writing the task list IS the update.

`<status>` blocks still cover planless turns; on platforms without editing
(email, WhatsApp, Reddit) it falls back to separate `⏳` notices
automatically. Only real multi-step work earns a task list — never force
one onto a one-line reply. Spec 5/24.

**Also: minting a chat-link/webhook token is default-deny.** `issue_chat_link`
/ `issue_webhook` create a PUBLIC unauthenticated endpoint, so they are absent
from the `role:member` floor. (This paragraph originally said "operator-only …
granted only under a `/root` elevation"; that was wrong — they are ordinary
delegatable grants. Corrected in migration 198.) If it's absent, that is the grant working, NOT an outage: tell the
operator to run `/root … issue_chat_link …`. You CAN `list_tokens` / `revoke_token`
your own folder's tokens without elevation. Never shell out to `mcpc` to reach a
tool that isn't in your native set — its absence is a permission answer.
