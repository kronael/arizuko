## v0.63.0 — packages, connectors, delegated grants

**Mostly operator features; one agent-visible change (grant delegation).**

- **`arizuko packages install|upgrade|remove`** — capabilities ship as packages
  (a git source or local dir carrying compose fragments, proxyd routes, grants,
  and skills). Routes/grants hot-apply to the live `routd.db` — no restart.
- **Surrogate OAuth connectors** — add a "Connect &lt;service&gt;" flow with a
  `<datadir>/surrogate/<name>.toml` drop-in + `SURROGATE_<NAME>_CLIENT_ID/_SECRET`.
- **Grant delegation (`WITH GRANT OPTION`, spec `5/33` phase 1)** — you may
  re-delegate a grant onward ONLY if you hold it WITH the option, and only a
  **subset** of what you hold. Authority strictly narrows down each chain; no
  depth number gates it. Root is a grant (`/root`), not a folder location. Tiers
  still back the default bundles for now — their full removal is the staged
  remainder of `5/33`.
- **`route_tokens` REST** now rides its resreg resource (one handler, both faces).
