## v0.61.2 — /root works from any folder (operator)

**Operator fix, no agent action.** `/root <cmd>` from a deep (tier-2+) folder
used to hit "tier N cannot …" and silently fail — the structural tier gate
ignored the elevation. It now lifts to tier 0 under `/root`, so an operator can
run `network_allow` / `add_acl` / `register_group` / cross-folder route + task
management from ANY folder.

For agents: the escalation the egress section teaches you — "ask an operator to
run `/root network_allow('your/folder', 'host')`" — now actually takes effect.
Keep giving the operator that exact command; it works.
