# Listing sources

Search property portals, agency sites and public community posts. Compare photos, location and source descriptions to identify duplicate listings. Check availability with the original source and record the date. Treat advertisements and social posts as leads, not verified ownership, zoning or availability.

ALWAYS open the live listing with a browser or curl before reporting its status or price. Search snippets only locate URLs. A 200 response alone does not prove an active listing; read the property details and withdrawal notices. If the live page is blocked, record the status and price as unverified.

Use the relevant country and local authority sources to verify each material claim. For Czech parcels use parcel-open-data and katastr. Record missing evidence as unknown. For pasture, check parcel boundaries, land use, access and zoning separately; do not infer availability from land type.
