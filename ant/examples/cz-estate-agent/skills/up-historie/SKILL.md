# Property history

Collect each available zoning plan, change, justification and related notice from the municipality and responsible offices. Record dates, sources, changes affecting the settlement and the property's zone in each version. Mark unavailable versions as unknown.

Compare dated historical maps and aerial images with the present parcel and building record. Verify map registration against visible features and printed parcel numbers. Record the source and image date for each observation. Compare registered buildings with evidence of construction, permits and use; do not infer legal status from an image. Use `zdroje-review` before delivery.
