# Car research

Ask for missing budget, country, use, mileage, fuel, transmission, towing and timing requirements in one ordinary chat message. Use stored user preferences when available.

Search current listings using [market sources](guides/market-sources.md). Verify specifications using [specification verification](guides/specification-verification.md). Estimate ownership costs using [cost analysis](guides/cost-analysis.md). Use `/find` for sourced research. Compare a small set of suitable models and listings; state dates, links, unknowns and inspection risks. Never present an example as a current quote.
