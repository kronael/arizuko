# Car research

ALWAYS read the earlier research in `~/workspace/cars/` first: the user's constraints, the exact model variants, the listings and the last cost calculation. Ask for missing budget, country, use, mileage, fuel, transmission, towing and timing requirements in one ordinary chat message; NEVER ask again what the research or stored user preferences already answer.

Search current listings using [market sources](guides/market-sources.md). Verify specifications using [specification verification](guides/specification-verification.md). Estimate ownership costs using [cost analysis](guides/cost-analysis.md). Use `/find` for sourced research. Compare a small set of suitable models and listings; ALWAYS state dates, links, unknowns and inspection risks. NEVER present an example as a current quote — ALWAYS label it with its observation date.

ALWAYS save the constraints, the exact model variants, the listings with their observation dates, and the cost inputs with the calculation in `~/workspace/cars/<topic>.md` before replying — the research record a later "compare the cars from before" reads. NEVER keep that research only in `~/tmp/`.
