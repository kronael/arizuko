Packages

A package is a git source (or local directory) that ships any subset of asset kinds as one versioned unit. Spec specs/5/28.

Commands

arizuko packages <instance> install github.com/org/pkg   # or a local dir
arizuko packages <instance> upgrade pkg                   # refuses locally-edited assets
arizuko packages <instance> remove  pkg                   # deletes exactly what it owns
arizuko packages <instance> list

Asset kinds

KindFileApplied to
compose fragment<name>.ymlservices/, up on generate
proxyd route<name>-routes.jsonlive proxyd_routes table — no restart
grant<name>-grants.jsonthe acl table
skillsskills/<name>/layered into every group like stock skills

How it stays safe

  • Each install writes an installed-package record (source + resolved revision + owned identities + a per-asset content hash).
  • upgrade compares the current content hash against the record; a locally edited (dirty) asset is refused, not overwritten.
  • remove deletes exactly the identities the record owns — routes are withdrawn before the fragment is dropped.

Installed packages are listed in the operator dashboard at /dash/packages/. A package that seeds a whole group is a product, applied at arizuko create --product.
