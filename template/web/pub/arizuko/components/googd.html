googd

googd is the Google Drive comments channel adapter. It can post a reply to an existing thread.

googd connects Drive comments to a channel

googd uses a service account to call the Drive API. The account must have access to the file.

Inbound polling is not built

The adapter cannot deliver new comments to routd yet. The file binding and message mapper exist.

googd connects routd to Drive

Thread replies. routd sends a thread JID to googd. googd posts the reply to Drive.

googd depends on arizuko

googd registers with routd and uses authd for service authentication. Set GDRIVE_SA_KEY_JSON to the service account key.
