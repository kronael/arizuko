reditd

reditd polls a list of subreddits and the inbox of the bot account, and replies with comments or DMs.

reditd connects Reddit to arizuko

reditd connects Reddit to arizuko, so the agent can watch subreddits and its inbox and reply with comments or DMs.

reditd is the Reddit channel adapter. It polls a configured list of subreddits and the inbox of the bot account for new posts, mentions and replies, and posts them to routd. It sends outbound messages with the Reddit comment and submit API. The JID prefix is reddit:. A post in a subreddit has the chat JID reddit:subreddit/<name>, and a message to the inbox has reddit:user/<author>.

Reddit has the only real downvote

Reddit is the only adapter platform with a real downvote. On every other platform, dislike becomes a thumbs-down reaction or a text reply. reditd uses the OAuth script-app flow: username and password with REDDIT_CLIENT_ID and REDDIT_CLIENT_SECRET. It keeps its cursors in cursors.json, so a restart does not read the inbox again.

reditd sits between Reddit and routd

Reddit (oauth.reddit.com)
        │  poll: /r/<sub>/new.json + /message/inbox.json
        ▼
      reditd     (LISTEN_ADDR=:8080)
        │  POST /v1/messages    (service:<daemon> ES256 bearer)
        ▼
      routd
        │  POST /send           (callback to reditd)
        ▼
      reditd     (POST /api/comment | /api/submit | /api/vote | /api/del | /api/editusertext)
        │
        ▼
      Reddit

The wired verbs are in reditd/client.go:

send, reply
/api/comment.
post
/api/submit kind=self.
like
/api/vote dir=1.
dislike
/api/vote dir=-1, the only native dislike of all adapters.
delete
/api/del.
edit
/api/editusertext, for self-posts and comments only.

send_file, forward, quote and repost return 501 with a hint.

reditd does not report inbound votes as like events. The Reddit API shows only the total score and ups of polled items, not single vote events. inbox.json covers only replies, mentions and private messages. For inbound messages, the agent sees verb=message, reply or post.

reditd runs alone with routd and a script app

reditd is a plain Go binary. It needs a reachable routd and a Reddit script app with the username and password of the bot account.

export ROUTER_URL=http://routd:8080
export AUTHD_URL=http://authd:8080
export AUTHD_SERVICE_KEY=$(grep ^AUTHD_SERVICE_KEY .env | cut -d= -f2)
export LISTEN_ADDR=:8080
export REDDIT_CLIENT_ID=<client id>
export REDDIT_CLIENT_SECRET=<client secret>
export REDDIT_USERNAME=mybot
export REDDIT_PASSWORD=<password>
export REDDIT_SUBREDDITS=arizuko_dev,programming
export REDDIT_USER_AGENT=arizuko/1.0
export DATA_DIR=/srv/data/arizuko_demo
./reditd

On the Reddit side, open old.reddit.com/prefs/apps, choose Create another app and select script. Do not choose a web app or an installed app: only a script app supports the password grant. Set the redirect URI to any value, because reditd does not use it. Copy the client ID and secret. GET /health returns 503 when the token refresh fails or the rate limit is full.
