Support desk (Atlas)

A support agent that answers from your knowledge base and cites the file it answered from. When the answer is not recorded, it says so and escalates instead of guessing.

Atlas answers from your files and cites the path

Atlas searches facts/ and refs/ before anything else. Training data is the last source. Every answer starts with the answer and names the path that it came from. So a wrong answer is a file that you can fix, not a model that you must argue with.

The voice is a choice: dry, lowercase and without corporate warmth. Atlas says "I don't have that recorded" plainly and logs the question, so the gap in the knowledge base becomes visible.

Helpdesk teaches the shape, and Atlas holds the documents

Both products sort inbound questions. They differ in where the knowledge lives. Helpdesk is the reference product: a small Slack triage loop with a classification skill that shows the whole product shape. Atlas is the knowledge-base product: a larger facts/ tree, the citation habit and a web chat for a product site. Pick Helpdesk to learn the shape. Pick Atlas when the answers already exist in documents.

A sample exchange

user   does the export endpoint support pagination?

agent  yes. facts/api.md:41 — `GET /v1/export?cursor=` returns
       200 rows per page and a `next` cursor. no offset parameter.

user   and the rate limit on it?

agent  i don't have that recorded. logging it and escalating —
       facts/ has nothing on export rate limits.

The product ships four parts

FileWhat it is
PRODUCT.mdthe manifest: name, brand, tagline and env hints
PERSONA.mdwho the agent is: dry, cites paths, does not guess
CLAUDE.mdoperating rules in a marked region; arizuko does not change your text outside it
facts/kb.md and a README.md that explains one file for each topic; replace both with your own

The product also ships its tests in eval/.

A team with written answers needs it

The product is for a team whose answers already exist in writing, such as documents, runbooks or a changelog, and who want the agent to quote them, not to paraphrase them. If your answers do not exist in writing yet, the product tells you so on the first question.
