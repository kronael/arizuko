CUZK cadastral lookup

Inspect one Czech cadastral property with the katastr skill.

The skill checks the territory and parcel number on the detail page. It records visible property details, source URL and observation time. Hidden ownership or rights remain unverified.

The lookup uses a controlled browser

The guest browser reaches CUZK through a host SOCKS relay. The skill keeps a quota ledger and stops for a CAPTCHA, login or service refusal. It does not perform bulk downloads.

Follow the setup guide to install the package and configure the relay.
