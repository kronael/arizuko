Learning assistant — setup

Krons needs one channel, a web host for the published site and the grants to publish and to research.

The assistant needs a host, a model key and a channel

  • A host with Docker and the build part of the install.
  • A model credential for Claude Code, Codex or pi. See the supported backends.
  • A Telegram bot token, TELEGRAM_BOT_TOKEN, or a WhatsApp adapter.
  • WEB_HOST, the host name that serves the published pages.

package add selects the product for a group

arizuko create -i learn
arizuko package add -i learn -g main github.com/kronael/arizuko/packages/learning-assistant
$EDITOR /srv/data/arizuko_learn/.env    # TELEGRAM_BOT_TOKEN, WEB_HOST, a model key

The command installs the group/ files, including the PERSONA.md of Krons, and the skills knowledge-site and research. Start the instance as a systemd service, as getting started shows. Select the adapter package and restart the service:

arizuko package add -i learn teled
sudo systemctl restart arizuko_learn
arizuko route -i learn add 'platform=telegram' main

Two grants let Krons publish and research

The folder needs web:publish to write ~/public_html/, and egress to read sources on the web. A scheduled refresh runs without the operator, so the folder holds both grants itself:

arizuko group -i learn grant folder:main main web:publish
arizuko group -i learn grant folder:main main egress

To allow only listed domains, skip the second grant and add the domains of the sources to the allowlist of the folder. The egress page explains the allowlist.

The first page starts the site

A new group has no pages, so the first questions start research. Before the first page, Krons writes the rules file of the site, ~/public_html/CLAUDE.md. The file holds the page-metadata namespace, the page types in archive order and the site title. Tell Krons the types and the title you want, or let it ask. Krons then copies hub.css and hub.js into ~/public_html/assets/ and writes the front page and the archive page.

Verify the site with the linter

Ask a question the site does not cover. Krons must answer with a page URL under https://WEB_HOST/pub/main/, and the page must open. Krons runs the linter before it announces a page. On the host, run it from an arizuko checkout with the namespace from /srv/data/arizuko_learn/web/pub/main/CLAUDE.md. It must exit 0:

sudo python3 packages/learning-assistant/skills/knowledge-site/scripts/site_lint.py \
  /srv/data/arizuko_learn/web/pub/main --www /srv/data/arizuko_learn/web/pub --ns NS
