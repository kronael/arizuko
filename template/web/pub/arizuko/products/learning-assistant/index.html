Learning assistant

Ask a question and get an answer from the pages the agent has already published, with the page cited. When no page covers it, the agent researches it and publishes one.

Krons is an agent for one user and one published site. The template is in packages/learning-assistant/.

The persona answers from the site first

The persona tells Krons to search the published pages before it researches, and to cite the page URL in the answer. It tells Krons to tag each claim [V] when a source checked it, [I] when it is inferred and [U] when it is unknown, and never to tag [V] a claim it did not check.

Four jobs make the assistant

Answer
Krons reads the pages under ~/public_html/ and answers with the page URL and the sources that page lists.
Research
For a topic the site does not cover, Krons searches with primary sources and publishes the result as a page with tagged claims.
Organise
Hub pages group related pages. A moved page leaves a redirect stub at the old path. A retired page goes to the archive. Krons never deletes a page.
Refresh
A scheduled task names a researched page. Krons rechecks its [V] claims, retags them and updates the date.

The persona is the first part of the package. The skills for publishing, linting and research follow it. The setup guide shows the install.

The package differs from two neighbours

Domain researcher
Delivers briefings on a watchlist. The learning assistant keeps a site that answers questions.
hub skill
Builds one page. The learning assistant keeps a whole site in order.
