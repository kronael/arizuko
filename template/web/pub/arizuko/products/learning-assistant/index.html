Learning assistant

Ask a question and get an answer from the pages the agent has already published, with the page cited. When no page covers it, the agent researches it and publishes one.

Krons is an agent for one user and one published site. The template is in packages/learning-assistant/.

The persona answers from the site first

The persona tells Krons to search the published pages before it researches, and to cite the page URL in the answer. It tells Krons to tag each claim [V] when a source checked it, [I] when it is inferred and [U] when it is unknown, and never to tag [V] a claim it did not check.

Four jobs make the assistant

Answer
Krons reads the pages under ~/public_html/ and answers with the page URL and the sources that page lists.
Research
For a topic the site does not cover, Krons runs the core find skill for primary sources and publishes the result as a page with tagged claims.
Organise
Hub pages list the pages of each section. A moved page leaves a redirect stub at the old path. A retired page leaves its hub and stays in the archive. Krons never deletes a page on its own.
Refresh
A scheduled task names a researched page. Krons rechecks its [V] claims, retags them and updates the date.

Two skills carry the four jobs

research
Answers from the site, researches what it does not cover, tags each claim and sets the refresh schedule of a page.
knowledge-site
Holds the page contract, the site order, a linter and the archive script. Every page has the same skeleton, built from page.html, hub.css and hub.js. The script hub.js runs the theme toggle and adds a banner to each research page.

Each site states its page-metadata namespace once, in ~/public_html/CLAUDE.md. Every page carries <meta name="NS:type"> and <meta name="NS:date"> with that prefix. The same file lists the page types and the site title.

The linter must pass before Krons announces a page

site_lint.py reports each finding as an error on one line and exits 1 on any finding. It has six rules:

html-balance
The first unclosed or stray tag on a page.
title-h1
An empty <title> or no <h1>.
links
An empty URL, a missing page or file, or a missing #fragment. A link that starts with / resolves against the directory that holds every published site.
css-class
A class that no loaded stylesheet or script defines.
page-meta
A missing or malformed NS:type or NS:date.
redirect-stub
A redirect stub whose target is missing or whose body links another page.

catalogue.py writes the archive page: every stamped page, grouped by type and newest first.

The package eval has four cases, and each case tests one line of the persona. The setup guide shows the install.

The package differs from two neighbours

Domain researcher
Delivers briefings on a watchlist. The learning assistant keeps a site that answers questions.
hub skill
Builds one page. The learning assistant keeps a whole site in order.
