PM agent setup

The PM agent needs one team channel and a list of the team members.

The agent needs an instance and one team channel

  • A running instance, from getting started.
  • One team channel. The product declares TELEGRAM_BOT_TOKEN and DISCORD_BOT_TOKEN as optional. Set at least one and install its adapter package. Without a channel, the board reaches nobody.

For Discord, select the adapter package. The existing selections stay:

arizuko package add -i <instance> catalog:discd

Then restart the running instance to start the adapter.

If systemd manages the instance, run sudo systemctl restart arizuko_<instance>.

group add makes the group from the product

arizuko group -i <instance> add discord:123456789/987654321 pm -p pm

The JID is discord:<guild_id>/<channel_id>. For a Discord server channel, the command writes a mention route and an observe route. The command also selects the product for the group. Sync to install it:

arizuko package sync -i <instance>

facts/team.md names the owners

facts/team.md gives an owner name its meaning. Without it, the agent cannot tell whether "mira" is a person or a service. List the members, their roles and how to reach them.

The facts/ files of the product are examples, not package files, so arizuko package sync never rewrites them. Copy them once from the repository checkout:

cp -r ant/examples/pm/facts /srv/data/arizuko_<instance>/groups/pm/

facts/tasks.md can stay as it ships. The agent adds rows, and an empty start avoids a board full of imported items that nobody owns.

The agent must confirm before it writes

arizuko send -i <instance> pm "add a task: rotate route tokens, owner mira, due friday" --wait

A correct answer confirms the owner and the deadline before it writes. If the agent writes at once, the persona is not in place. Check groups/pm/PERSONA.md, which SOUL.md becomes at the first turn.

A scheduled task writes the weekly status

Ask for the status, or schedule it. A scheduled task is a scheduled_tasks row that the tool of the agent makes. Tell the agent "post the status summary every Monday at 9", and it makes the row. Products ship no task files. Scheduled tasks explains why.

Three changes tune the agent

Board shape
Edit facts/tasks.md directly. The file is the source of truth, not a copy.
Escalation
The agent reports blocked and late items. facts/team.md decides whom it contacts.
Voice
Edit the persona file.
