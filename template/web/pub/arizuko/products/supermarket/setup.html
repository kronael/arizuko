Supermarket price agent — setup

One folder, one route and one channel give a working price agent with few steps after arizuko create.

The agent needs KVM, a model key and one channel

  • A host with Docker, and a public hostname for web chat or a Telegram bot token.
  • The build part of the install: the binary, the images and the guest kernel, with DATA_DIR set to the data directory of this instance. A turn is one KVM guest, so the host needs /dev/kvm.
  • Anthropic API access.
  • Optional: TELEGRAM_BOT_TOKEN for a Telegram channel. Without it, web chat works alone.

create writes the instance and its .env

arizuko create shop
$EDITOR /srv/data/arizuko_shop/.env

arizuko create writes .env with ASSISTANT_NAME, a new AUTH_SECRET and a new SECRETS_KEY. Add the values that it cannot know:

WEB_HOST=shop.example.com          # public hostname
WEB_PORT=8095                      # starts proxyd and webd for web chat
ANTHROPIC_API_KEY=sk-ant-REPLACE_ME

# Optional: Telegram
TELEGRAM_BOT_TOKEN=REPLACE_ME

For Telegram, also install the adapter: arizuko packages shop add teled.

group add makes the folder, and one route catches every message

arizuko group add writes the group row, makes the folder and adds a route for the given JID. Then add the catch-all route. An empty match matches every message, as the CLI reference shows:

arizuko group shop add web:supermarket supermarket
arizuko route shop add '' supermarket

For Telegram only, without web chat and webhooks, use a narrower match:

arizuko route shop add 'platform=telegram' supermarket

For many route changes at once, declare the routes in a YAML manifest and run arizuko apply shop shop-routes.yaml. The routes page of the dashboard at /dash/routes/ also works.

Two files tell the agent what to search

The agent reads facts/retailers.md before every search. Write the retailers that it must check:

mkdir -p /srv/data/arizuko_shop/groups/supermarket/facts
cat > /srv/data/arizuko_shop/groups/supermarket/facts/retailers.md <<'EOF'
# Retailers

## Tesco
URL: tesco.com/groceries
Notes: Clubcard prices require a Clubcard account; list both regular and Clubcard prices.

## Sainsbury's
URL: sainsburys.co.uk/groceries
Notes: Nectar prices available; list both.

## Lidl
URL: lidl.co.uk/grocery
Notes: Prices update Thursday. Note the week-start date in replies.
EOF

Add or remove retailers as you need. The agent uses this file as its only source list and searches no other retailer.

The CLAUDE.md of the group holds the instructions of the agent. The product ships no template, so write the file yourself. It makes the cache and the citations of the intro page true:

cat > /srv/data/arizuko_shop/groups/supermarket/CLAUDE.md <<'EOF'
# Supermarket price agent

Answer "where is X cheapest" questions. Read facts/retailers.md first;
search only the retailers listed there. Always cite source URLs.

Cache results in facts/cache/<item>-<YYYYMMDD>.md. Before searching,
check the cache; a file dated today answers without a new search.
Ignore cache files older than one day.
EOF

Egress must allow the retailer domains

The agent needs outbound access to the retailer domains. Allow them through egress:

arizuko network shop allow supermarket tesco.com
arizuko network shop allow supermarket sainsburys.co.uk
arizuko network shop allow supermarket lidl.co.uk

The proxy blocks every domain that the list does not allow. The agent then says that it could not reach the site and does not return old data.

arizuko run starts the instance

arizuko run shop

For production, run the instance as a systemd service, as getting started shows.

A web chat token gives a chat URL without Telegram

arizuko token shop issue chat supermarket
# prints the token; the chat URL is https://shop.example.com/chat/<token>/

To put the chat into your own page, load https://shop.example.com/assets/arizuko-client.js and use its connect, send and stream calls. Chat SDK shows how.

A price question must get a cited answer

  • arizuko status shop shows all services up.
  • On Telegram, ask the bot a price question. It must reply with sources.
  • For web chat, open https://shop.example.com/chat/<token>/ in a browser and ask a price question.
  • Run sudo journalctl -u arizuko_shop --since "5 min ago" | grep -iE 'error|fatal' to find problems.

The group files control the behaviour

Edit the files in the group folder. Every path under /srv/data/arizuko_shop/groups/supermarket/ is also available over WebDAV at https://shop.example.com/dav/supermarket/ for a signed-in operator.

Voice and citation format
Edit CLAUDE.md in the group folder, for example the number of retailers to compare, unit prices, and the answer when a price is not available.
Cache time
The agent caches results in facts/cache/ by item and date and ignores files older than one day. To force new results, delete the cache files: rm /srv/data/arizuko_shop/groups/supermarket/facts/cache/*.md.
Load limit
MAX_CONCURRENT_CONTAINERS in .env limits the concurrent turns, default 5. Each search is one guest.
