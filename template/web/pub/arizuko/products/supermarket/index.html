Supermarket price agent

This is a shape, not a template. No tree ships for it in ant/examples/, so there is no --product supermarket to run. The page describes how the product is assembled from the primitives; every command below is one you run yourself. The catalog marks which products ship as templates.

“Where’s milk cheapest this week?” — the agent searches, compares, and replies with sources. One shared folder serves everyone who asks.

One folder and one route serve every user

The supermarket agent is the smallest product shape. It has one folder, one catch-all route and no per-user state. The six steps of the pipeline are at their smallest:

Event
A Telegram message, a web chat message or a webhook POST. All arrive as rows in the same inbox. The agent does not know which channel sent a message.
Routing
One catch-all route sends every inbound message to the supermarket folder. No per-user routing and no topics exist.
Agent
The folder holds a PERSONA.md with the rules for price questions, a CLAUDE.md with the allowed tools, the citation format and the refusals, and facts/retailers.md. The operator writes that file: the retailers to check, their URLs and their known problems, for example late price dates or member-only prices.
Authorization
The route is the only fence. Anyone who reaches the bot or the chat URL can ask. No per-user ACL rows exist.
Turn
One short-lived guest for each question. The agent reads facts/retailers.md, searches the named retailers on the live web and replies. It caches the results in facts/cache/ by item and date, so a second question about the same item on the same day needs no search.
State
The message rows on the store server, and the folder on disk: facts/retailers.md and facts/cache/. No per-user folders and no memory files exist. Nothing carries over from one user to the next.

The structure is the same for ten users or ten thousand. The limit is the number of concurrent guests, MAX_CONCURRENT_CONTAINERS, default 5, not the number of users. Users do not register.

A sample exchange

telegram · DM

  user   where's the cheapest whole milk this week?
  agent  Checked Tesco, Sainsbury's, Lidl (prices as of today):
         Tesco: 2L semi-skimmed £1.09 (Clubcard price £0.95)
         Sainsbury's: 2L whole milk £1.10
         Lidl: 2L whole milk £0.99

         Cheapest: Lidl £0.99.
         source: lidl.co.uk/grocery/dairy, tesco.com/groceries, sainsburys.co.uk

The agent checks three retailers and names the sources. No login, no sign-up and no memory of who asked. The next user gets the same search and the same sources, or the cached prices of the day, which need no search.

The shape leaves out five features

  • No per-user memory. Every user starts with nothing.
  • No folder tree. One folder on one level.
  • No grant rows. The route is the fence.
  • No scheduled tasks. The agent runs only when a message arrives.
  • No OAuth, no linked identities and no web dashboard for users.

The company brain is at the other end: a folder tree that follows the org chart, per-team memory, scheduled briefs, several input sources and ACL rows for each folder. The pipeline is the same, and the folder contents are very different. Start with the supermarket shape, and use the larger one only when you need its structure.

No user data is collected

Your server
The message history is on the store server of the instance. The cached prices are files under /srv/data/arizuko_<name>/groups/supermarket/.
Outbound paths
The channel, Telegram or web chat, for the bot; Anthropic for model calls. Web search goes through the egress proxy of the turn. Allow the retailer domains that the agent must reach.
No user data
No per-user memory files, no linked identities and no email addresses exist. The only persistent state is the cache and the message log.

Six commands set it up

arizuko create shop
$EDITOR /srv/data/arizuko_shop/.env                 # TELEGRAM_BOT_TOKEN, or nothing for web chat only
arizuko group shop add web:supermarket supermarket   # make the folder
arizuko route shop add '' supermarket                # catch-all: every channel
$EDITOR /srv/data/arizuko_shop/groups/supermarket/facts/retailers.md
arizuko run shop

The operator setup guide has every step. A web chat token gives a chat URL that you can open or embed without a platform adapter, which fits a quick internal deployment.
