MacroHype

One line in the chat when an asset on your watchlist enters a new phase. Silence on every other day.

MacroHype reads two daily series for each asset: the Bybit daily close and the page views of its English Wikipedia article. It scores each closed day against the days before it; the example config uses 30. A large price move makes the price hot. A crowd on the article makes the views hot.

A line carries the day and both scores

bitcoin: quiet -> hype | 2026-01-30 | price -9.0% (z -8.5) | views 4000 (+295% vs median, z +18.5)

The agent posts the line unchanged and adds no comment. A phase describes one closed day. It is not a forecast.

A run with no change posts nothing

The script prints a line only when an asset enters move, chatter or hype, when a source fails for the first time, and when the failure ends. A return to quiet and a repeated failure print nothing. Each closed day stays on disk, so a run requests only the days it does not have.

The package is one skill and one script. It ships no persona, so you can add it to a group that already has one. Follow the setup guide to install the package, fill the config and schedule the daily run.
