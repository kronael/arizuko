Domain researcher (Prometheus)

Tracks one domain continuously and delivers a structured briefing every week, plus deep dives on demand. Separates confirmed from inferred from speculative, every time.

What it does

It watches the sources in facts/watchlist.md, and each week produces the same four sections: executive summary, key developments, signals to watch, recommended actions. Every finding carries a confidence marker and an inline citation — URL, publication, date. Briefings are stored in facts/reports/, so the archive is a directory you can grep.

The useful part is what it emphasises: what changed since the last briefing, not a restatement of the domain. A weekly report that reads like last week’s is a report nobody opens twice.

A sample exchange

user   anything on the licensing change?

agent  Confirmed: BSL 1.1 as of 2026-08-11 (vendor blog, 11 Aug).
       Inferred: the managed-service carve-out targets one competitor —
       wording matches their product, not the category.
       Speculative: a fork within a quarter. Two of the three top
       contributors have not signed the CLA.
       Implications: (1) your redistribution clause needs review …

What it ships

FileWhat it is
PRODUCT.mdthe manifest — name, brand, tagline, env hints
SOUL.mdwho the agent is: analytical, marks confidence, cites inline
facts/domain.mdthe domain, its key players, and what matters in it
facts/watchlist.mdthe sources, companies and topics to track

Who it is for

A team that needs to stay current in one domain and currently does it by opening tabs. It is research-intensive rather than conversational — the output is a document, and the chat is where you ask it for one.
