CZ Estate Agent

Check whether an estate fits your search, especially Czech properties for stables and pasture.

The agent checks the cadastre, zoning plans and listings against each other. It records sources, dates and unknowns in the group's files.

One search brief guides the research

The listing-research skill reads the criteria in ~/estate/site.json. Location, buildings, pasture and access belong to that group.

The package supplies listing research, parcel checks, valuations, municipality profiles, financing calculations and a generated property site. The site checker checks numeric tables, headings and valuation placement before delivery. It does not verify the sources.

Two uses demonstrate the same package

Czech estates for stables
Compare buildings, existing pasture and nearby land against the brief. Check parcel identity, access, zoning and possible pasture expansion separately. Adjacent land does not prove availability.
A local Portugal search
Use the listing research and site tools with the group's own criteria and local sources. Keep this variation in the group. Czech cadastral tools apply only to Czech properties.

The agent separates evidence from assumptions

The agent asks which property and goal to research. It does not infer a parcel from its area or call land buildable from its land type. Hidden ownership and rights remain unverified.

The cadastral lookup uses a controlled browser through a host SOCKS relay. The skill keeps a quota ledger and stops for a CAPTCHA, login or service refusal.

Chat starts the search and the site keeps the results

A personal or shared chat can carry the brief. The group keeps the listing table and property pages on your server.

user    Find estates for stables with adjacent pasture.
agent   Which search area, land requirements and budget should I use?
user    Use the criteria in our search brief.
agent   I will compare listings and record the evidence and unknowns.

Follow the setup guide to install the package and configure its sources.
