CZ Estate Agent — setup

Install the package, set the search criteria and allow its sources. Czech cadastral lookup also needs a host relay.

Select the package

Select the package for the group. The command installs it.

arizuko package add -g FOLDER github.com/kronael/arizuko/packages/cz-estate-agent@v0.75.8

The standard agent image supplies the browser and its support tools. Installation sends no CUZK requests.

The group owns its search criteria

Set criteria in ~/estate/site.json for location, buildings, pasture, access and budget. The listing skill asks for missing requirements.

Keep a Portugal search as a local variation over this package, with its own criteria and sources. Allow those source hosts through network_rules.

Configure the relay for Czech cadastral lookup

Provide SOCKS on 127.0.0.1:1080. Install the package’s two transport units and enable cuzk-socks@1081.socket. Restrict the relay’s source network with the host firewall. The relay accepts arbitrary SOCKS targets and does not authenticate groups.

Permit host.docker.internal in the group’s egress grant. Set KATASTR_RELAY_PORT if the relay uses another port. The open-data skills also need ags.cuzk.gov.cz, services.cuzk.cz, katastrnemovitosti.cz and volby.gov.cz.

Check the listing site before delivery

After updating ~/estate/db.md, build the site and check its output:

python3 ~/.claude/skills/estate-site/scripts/gen_site.py build
python3 ~/.claude/skills/estate-site/scripts/check_format.py --config ~/estate/site.json ~/public_html/index.html

Pass each changed property page to the same checker. Check the page in a browser at 390 px width and verify the published URL.

Preserve the quota ledger

Keep the browser profile and quota history under ~/tmp/katastr when updating the package. Verify browser access in a guest. An HTTP response alone does not prove ownership details are visible.

The package guide lists the commands and transport units.
