Company brain — setup

Install the package, then fill the one config file the digest scripts read.

Select the package

arizuko package add -g FOLDER ant/examples/brain

Fill the config

The digest skill ships digest.example.toml; copy it to ~/digest.toml in the group once, then edit it. Replace the repository, the clone path, the post chat, the agent’s accounts, the people and the channels. The scripts stop when the file is missing.

Credentials

Set DISCORD_BOT_TOKEN for the channel. Give the group a GitHub token as GH_TOKEN; without it the digest reads the local clone and the message store.

Schedule it

Add a daily task that runs /digest and a Monday task that runs /digest --week with the weekly state file. Use --preview with a test chat before the first post to the team channel.
