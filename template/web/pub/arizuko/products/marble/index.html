Taxonomy chat (Marble)

This is a shape, not a template. No tree ships for it in ant/examples/, so there is no --product marble to run. The page describes how the product is assembled from the primitives; every command below is one you run yourself. The catalog marks which products ship as templates.

“What does a child need to learn before fractions?” — the agent traces the prerequisite graph of an open education dataset and answers in plain words. One folder, one bundled dataset, a public chat widget anyone can open.

The agent reads a dataset in its folder

Marble is a read-only knowledge bot over a fixed dataset. The supermarket agent searches the live web at each turn. This agent queries a dataset inside its folder, with no outbound fetch for data and no per-user state. The six steps of the pipeline are at their smallest:

Event
A message from the public web chat arrives as a row in the inbox of the folder. No platform adapter and no login exist. A /chat/<token>/ link is the only entrance.
Routing
One route maps the JID of the chat to the marble folder. Every visitor shares the folder.
Agent
The folder holds a CLAUDE.md, with who the agent is and how it answers and cites, and a taxonomy/ directory with topics.json, dependencies.json and clusters.json. The agent answers with jq over those files: it follows a prerequisite chain, lists what a topic opens, or filters by subject or age.
Authorization
One public chat token. Anyone with the link can ask. No per-user ACL rows exist.
Turn
One short-lived guest for each question. The agent reads the JSON, follows the graph and replies with the topic names. It writes nothing back.
State
The message rows on the store server and the dataset on disk. No per-user folders and no memory files exist. The dataset is reference data, so nothing collects from one visitor to the next.

A sample exchange

web chat · public link

  visitor  what does a child need before fractions?
  marble   Before fractions, these foundations come first:
           whole-number place value, equal sharing / partitioning,
           multiplication as equal groups, and division as sharing.
           Each is a prerequisite edge into "Introduce fractions".

  visitor  what's the deepest chain in the taxonomy?
  marble   Understanding Earth's atmosphere (for 10-11-year-olds)
           requires learning 9 other topics first - the longest
           prerequisite chain in the graph.

The example uses the Marble Skill Taxonomy v1: 1,590 micro-topics for grades K to 5, connected by 3,221 prerequisite edges across 8 subjects. It is the open-data version of the interactive curriculum graph on withmarble.com/curriculum, with an agent that you talk to instead of a page that you click.

The shape adds a dataset and a small model

Like the supermarket agent, Marble is at the small end of the range:

  • No per-user memory. Every visitor starts with nothing.
  • No folder tree. One folder on one level.
  • No grant rows. The chat token is the fence.
  • No web search. The dataset is on disk, and the guest goes outside only for the model call.

Marble adds a bundled knowledge base and a small model. A public bot that answers lookup questions does not need a large model. Set it to Haiku and remove most skills, and each answer costs little and comes fast. The setup guide shows both steps.

No user data is collected

Your server
The dataset is a set of files under /srv/data/arizuko_<name>/groups/. The message history is on the store server of the instance.
One outbound path
Anthropic, for model calls. No web search exists, because the taxonomy is in the folder.
No user data
No per-user memory, no linked identities and no email exist. The only persistent state is the message log.
Licence
The Marble Skill Taxonomy is © Marble, withmarble.com, under CC BY-SA 4.0. Keep the attribution in the CLAUDE.md of the agent and cite it in replies.

Four commands set it up

arizuko group <instance> add web:<folder> <folder>   # make the public group
cp taxonomy/*.json /srv/data/arizuko_<instance>/groups/<folder>/taxonomy/
# set the model to Haiku and remove skills at /dash/groups/<folder>/settings
arizuko token <instance> issue chat <folder>    # make the public chat link

The operator setup guide has every step: the group, the dataset, the instructions, the model, the skills and the link.
