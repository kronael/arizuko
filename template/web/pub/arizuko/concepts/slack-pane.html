slack pane

The Slack pane is a feature that only Slack offers, and the agent can use it where it exists. Slack has a sidebar for installed agent apps: the user clicks the AI icon and gets a split pane with the bot. The pane does more than a DM. The bot can set a title, suggest follow-up prompts, show a typing indicator, and know which channel the user is looking at. On a platform with no pane, the same tool calls do nothing, so the agent does not branch on the platform.

The pane is a Slack thread with extra events

The pane is a special Slack thread with a fixed thread_ts that Slack opens when the user clicks. Slack sends two extra events to the app. assistant_thread_started arrives when the user opens the pane. assistant_thread_context_changed arrives when the user moves to another channel while the pane is open. In the other direction, the app can call assistant.threads.setStatus, setTitle and setSuggestedPrompts.

The pane adds four things a DM lacks

A DM is only a message stream. The pane adds four things:

Title
The pane history shows what the conversation was about, not only “chat with bot”.
Suggested prompts
Starter buttons at the bottom of the pane. The agent sets them with pane_set_prompts after a reply, so the next click is fast.
Typing indicator
setStatus("thinking…") while the agent runs.
Pane context
The bot can read which channel the user was looking at when they clicked the AI icon, and refer to it.

slakd records each pane and starts it

For each pane, slakd stores a row in pane_sessions with the key (team_id, user_id, thread_ts). The row holds the DM channel of the pane and the optional context_jid that the user is looking at. When assistant_thread_started arrives, slakd does four things:

  1. It writes or updates the pane_sessions row.
  2. It sets the pane title with bot.paneTitle(): “<assistant> — chat” when ASSISTANT_NAME is set, and “chat” otherwise.
  3. It sets default suggested prompts from the starter list in the bot. The agent replaces them per pane with pane_set_prompts calls.
  4. It creates an inbound message with verb="pane_open", so the route table can match it.

On every agent reply in a pane, slakd posts with chat.postMessage and sets thread_ts to the thread of the pane. It then calls setSuggestedPrompts if the agent set prompts with pane_set_prompts.

Two MCP tools control the pane

pane_set_prompts(jid, prompts)
Sets 3 or 4 follow-up buttons that appear after the next reply.
pane_set_title(jid, title)
Replaces the pane title for the current conversation.

On platforms without a pane, such as Discord and Telegram, both tools do nothing.

Three settings in the Slack app turn the pane on

In the Slack app configuration at api.slack.com/apps:

  1. Turn on Agents & AI Apps.
  2. Under OAuth scopes, add assistant:write and keep chat:write.
  3. Under Event Subscriptions, subscribe to assistant_thread_started and assistant_thread_context_changed. Keep message.im for inbound pane messages.

deploy on Slack has the full steps.

The reference pages list the table and the tools

reference / schema has the pane_sessions table. pane_set_prompts and pane_set_title are in the MCP tool reference. slakd describes the adapter.
