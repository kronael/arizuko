# Notice boards

Identify the municipality, verified neighbours and responsible planning and building offices. Search current notices and archives through every page. Record each board's URL, coverage, item count and any access gaps. Open relevant documents for parcel, planning, building and council references. Record exact deadlines, submission recipient and publication dates from the source. Record searches with no matches. Do not bypass access restrictions. Use `zdroje-review` before delivery.
